АКТ ОСМОТРА АВТОМОБИЛЯ — программа для АвтоБрокера
===================================================

ВАРИАНТ 1. Без установки (сразу)
  Дважды кликните akt_osmotra.html, бланк откроется в браузере.
  Заполняйте с клавиатуры, галочки ставьте мышкой.
  Кнопки: «Сохранить…» (файл .json попадёт в «Загрузки»), «Открыть…»,
  «Печать / PDF», «Новый акт».

ВАРИАНТ 2. Программа AktOsmotra.exe (своё окно и иконка)
  1. Нужен Python 3.10+ (python.org, при установке отметить "Add python.exe to PATH").
  2. Дважды кликните build.bat. Скрипт сам установит нужные пакеты
     и соберёт программу. Это 1–3 минуты.
  3. Готовая программа появится в папке dist\AktOsmotra.exe.
     Её можно скопировать на рабочий стол или на флешку, Python для запуска больше не нужен.
  Акты сохраняются по умолчанию в «Документы\Акты осмотра».

ПОЛЕЗНОЕ
  - Черновик сохраняется автоматически: закрыли окно, открыли, данные на месте.
  - VIN можно вставить целиком (Ctrl+V) в первую клетку, он разложится по клеткам сам.
  - Enter переходит к следующему полю.
  - В строке «Норма / Дефект» можно отметить только одно.
  - На втором листе № акта, модель и VIN подставляются автоматически.
  - Печать: в окне печати выберите «Сохранить как PDF» или принтер,
    поля = нет, «Фоновая графика» = включить.
